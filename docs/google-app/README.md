# imprint-sync (`imprint-sync-lesen`)

| Property | Description |
|---|---|
| Application | `imprint-sync-lesen` (OAuth client ID in Google Cloud project `imprint-sync`) |
| Nature | Personal, self-hosted, read-only desktop archive tool |
| Audience | Single user (the repository owner only; not offered to others) |
| Hosting | Local workstation only (no cloud service, no external backend) |
| Scopes | Read-only access to Gmail, Google Contacts, and Google Calendar |
| Privacy Policy | [Privacy Policy](privacy.md) |
| Contact | Open an issue in this repository |

`imprint-sync-lesen` is a personal, self-hosted, read-only desktop archiving utility used exclusively by its single owner on their own computer. It is part of the `imprint` project and is used solely to create local archival snapshots of the owner's own data.

The application is not a public service, SaaS, or commercial product, and is not offered or made available to anyone else.

## Privacy and Permissions

Details regarding data handling, storage, and access revocation are documented in the [Privacy Policy](privacy.md).

## Contact

To report an issue, open an issue in this repository on GitHub. No email support is provided.

`imprint-sync-lesen` ist ein persönliches, selbst-gehostetes Nur-Lese-Archivwerkzeug für den Desktop, das ausschließlich vom Inhaber auf dessen eigenem Rechner verwendet wird. Es ist Teil des `imprint`-Projekts und dient ausschließlich der Erstellung lokaler Archivkopien der eigenen Daten des Inhabers.

Die Anwendung ist kein öffentlicher Dienst, kein SaaS-Produkt und kein kommerzielles Angebot. Sie wird keinen anderen Personen angeboten oder bereitgestellt.
